# Code Review

## 언제 쓰나
- 구현 직후, 커밋/PR 전에.

## 체크리스트
- **정확성** — 요구사항 만족? 엣지 케이스?
- **회귀** — 기존 동작을 깨뜨리지 않았는가?
- **테스트** — 새 로직에 테스트가 있는가? 빠진 케이스?
- **보안** — 입력 검증, 비밀값 노출, 인젝션 위험?
- **가독성** — 6개월 뒤의 내가 이해하는가?

## 산출물
- 문제를 우선순위(critical/minor)로 정리하고 각각 수정 또는 사유를 남긴다.
