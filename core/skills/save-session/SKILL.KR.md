## Save Session

### 사용 시점
- 세션이 길어져 컨텍스트가 요약되거나 곧 끝날 것 같을 때.
- 다음 세션에서 이어갈 작업이나 미해결 이슈가 남아있을 때.

### 절차
1. 이번 세션에서 **한 일**을 3~5줄로 정리한다.
2. **내린 결정**과 그 이유를 정리한다.
3. **다음 단계 / 미해결 이슈**를 정리한다.
4. 프로젝트 루트 기준 `memory/sessions/YYYY-MM-DD-<주제>.md`로 저장한다 (폴더가 없으면 생성한다).
5. `memory/`는 팀과 공유하는 산출물이 아니라 개인 작업 기록이므로, `.gitignore`에 추가하는 것을 권장한다.

### 형식
```
# <날짜> — <주제>

## 한 일
- ...

## 결정
- ...

## 다음 단계
- [ ] ...
```
