## 워크플로우

모든 기능/수정 작업은 다음 단계를 따라 수행한다:

```
계획 수립 → 테스트 → 구현 → 리뷰 → 검증 → 기록 저장
```

1. **계획 수립** — 코드 작성 전 계획 세우기 (skills/plan)

2. **테스트** — 구현 전 실패하는 테스트를 우선 작성 (skills/tdd-workflow)

3. **구현** — 테스트를 통과하는 최소 코드를 작성

4. **리뷰** — 새 관점에서 작업을 점검 (skills/code-review)

5. **검증** — build, lint, types, tests를 모두 확인

6. **기록 저장** — 긴 세션 종료 시 요약 (skills/save-session)
